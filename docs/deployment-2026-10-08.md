## Доступ с компьютера разработки

В ходе этого этапа открыт SSH-туннель:

```sh
ssh -N -L 127.0.0.1:18191:127.0.0.1:18190 -p 22 epopov@192.168.1.90
```

Серверный интерфейс: [http://127.0.0.1:18191](http://127.0.0.1:18191).
Адрес http://127.0.0.1:18190 на компьютере разработки по-прежнему относится к предыдущему локальному MVP. Не перепутать их ключи и данные.

Ключ серверного интерфейса безопасно скопирован по SSH в secrets/server_app_token на компьютере разработки, права файла 0600 внутри защищённого каталога secrets. Его значения не выводились. На macOS скопировать в буфер:

```sh
pbcopy < secrets/server_app_token
```

Вставить в поле ключа серверного интерфейса. Если туннель перестанет работать после завершения сессии приложения, открыть его приведённой выше командой.
