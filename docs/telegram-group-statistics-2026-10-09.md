# Групповая статистика Telegram

09.10.2026. Группа пользователя: PSPTM_AIForce.

`/stats@bender_svetlanovna_bot` — текущие счётчики за всё время. `/stats@bender_svetlanovna_bot today` — сегодня по Москве. Кнопки «Обновить», «Сегодня» и «За всё время» создают новый ответ с актуальным снимком. Доставка ограничена одним ответом на группу за пять секунд, повторы учитывают 429.

Показатели: входящие обращения к боту, пользователи бота, встречи и состояние транскриптов, разборы встреч, готовые/ожидающие/ошибочные отчёты, черновики/утверждённые/в работе/выполненные поручения. Счётчики охватывают приложение целиком, включая старые веб-загрузки. «Отчёт» — отдельный сохранённый результат шаблона; «разбор встречи» — общее состояние набора её отчётов. Вызовы AI, токены и длительность инференса этой версией не измеряются.

За сегодня встречи учитываются по created_at, разборы и отчёты по updated_at; это состояние записей на момент запроса, а не журнал всех исторических генераций. Пользователи и поручения показываются текущим итогом: у поручений нет даты создания. Учёт входящих обращений начинается с этой версии; старые обращения не восстанавливаются. Сохраняются только ID обновления, категория и время, без содержимого сообщений и идентификатора отправителя.

Только числовой TELEGRAM_STATS_CHAT_ID разрешает отправку. Название группы служит для обнаружения, но не авторизации. Неизвестные группы сохраняются как кандидаты по запросу /stats или событию членства; цифры им не отправляются. Личные callbacks статистики не дают доступ к глобальным счётчикам. Персональные меню, записи, отчёты, названия встреч, люди, цитаты и поручения в группу не отправляются. Групповые команды записи и изменения поручений не поддерживаются.

Команды и их доставка устойчивы к повтору update_id и перезапуску. При неопределённом результате sendMessage повтор может создать дубликат. Для получения адресной команды достаточно обычного участия бота; отключать privacy mode не требуется: https://core.telegram.org/bots/faq#what-messages-will-my-bot-get.
