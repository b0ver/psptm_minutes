# ADR 0006: открытый вход в Telegram и личные материалы

Дата: 09.10.2026. Статус: принято по решению пользователя.

## Решение

Telegram-бот работает отдельным Docker-сервисом с long polling. Вход открыт всем при TELEGRAM_ALLOW_ALL=1, но только в личных чатах. Telegram user ID определяет владельца сессий и встреч; доступ к каждой кнопке, команде, уведомлению и поручению проверяется по владельцу в PostgreSQL. Старый архив не назначается первому посетителю и не раскрывается автоматически.

В Telegram передаются названия, статусы, управление записью и разбором, а также явно утверждённые карточки поручений. Исходные записи, транскрипты, полные отчёты и доказательные цитаты остаются локально. Присланные медиа бот не скачивает. Общий веб-интерфейс без авторизации не публикуется для пользователей бота. AI использует локальную Ollama; Telegram не участвует в обработке материалов.

Перед запуском видимого участника Телемоста пользователь подтверждает разрешение на запись. UUID команды является ключом запуска агента: неопределённый ответ сверяется с прежней сессией. Диалоги имеют срок действия, команды и ответы сохраняются до сетевого запроса. Singleton advisory lock ограничивает обработку обновлений одним ботом. Гарантии exactly-once доставки сообщений нет.

## Последствия

Новые посетители имеют пустой личный список до собственной записи. Для передачи исторических веб-загрузок потребуется отдельная явная процедура назначения владельца; её нет в этой версии. Группы, расписание, локальная загрузка через Telegram, поиск по транскриптам и Mini App остаются вне текущего объёма. Токен передаётся только контейнеру Telegram, не API, агенту записи или AI-обработчикам.

## Дополнение 09.10.2026: экспорт по запросу

Пользователь прямо запросил скачивание Markdown встреч по разделам из бота. Это разрешение на передачу конкретных собственных материалов через Telegram по нажатию кнопки: транскрипт, выбранный готовый отчёт или все готовые разделы. Новая возможность доступна только в личном чате владельца, с проверкой как при постановке команды, так и при доставке. Автоматическая рассылка полного содержимого и экспорт в группы не включаются. Группа PSPTM_AIForce получает только агрегаты по явно заданному числовому ID.
