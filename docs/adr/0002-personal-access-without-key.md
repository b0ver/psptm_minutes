# ADR 0002: личный доступ через SSH без ключа приложения

Дата: 8 октября 2026. Статус: принято владельцем («давай убирать да»).

## Решение

Для текущего личного использования удалить административный Bearer-ключ из API и интерфейса. Пользователь сразу видит загрузку и реестр. Ключ не читается при старте API, не генерируется bootstrap и не монтируется в API через Compose. Интерфейс удаляет ранее сохранённый minutes-key из sessionStorage и больше не отправляет Authorization.

Порт API остаётся опубликованным только на 127.0.0.1; удалённый доступ осуществляется существующим SSH-туннелем. Этот режим разрешает чтение записей и изменение реестра любому пользователю или процессу с доступом к локальному порту. Персональных аккаунтов и разграничения прав нет.

Чтобы обычная посторонняя веб-страница не могла отправить изменяющий запрос через браузер, API отклоняет POST/PUT/PATCH/DELETE с чужим Origin или Sec-Fetch-Site: cross-site. Это проверка происхождения браузерного запроса, не идентификация пользователя и не защита от локальных программ. Запросы без Origin допустимы для локальных клиентов.

## Последствия

Форма загрузки не содержит поля ключа, кнопок входа и выхода. Все чтения и изменения работают без Bearer-токена. Ограничение размера файла остаётся снятым; проверка формата и пустого файла, сохранение по частям, проверка версии поручения и подтверждение перед утверждением сохраняются.

Для расширения доступа по сети потребуется отдельное решение об авторизации. Docker, Ollama на хосте, локальная обработка, внутренний реестр и отключённый Telegram остаются по ADR 0001. Настоящие секреты PostgreSQL/Telegram этим решением не удаляются. Старые файлы ключа остаются неиспользуемыми и исключёнными из Git; их содержимое не выводится.

## Проверка

Тестовый клиент больше не добавляет Authorization. Проверяются загрузка и чтение без ключа, разрешённый Origin своего интерфейса, отказ чужому/null Origin и cross-site, а также существующие проверки обработки, поручений и больших загрузок. Browser smoke проверяет открытое пространство, отсутствие формы входа, очистку старого sessionStorage и загрузку без Authorization. Синтетическая загрузка в браузере перехватывается, реальные AI-задачи для проверки не создаются.
