# Интеграция Telemost Meeting Kit — 8 октября 2026

## Что перенесено

Исходный набор из Downloads/telemost-meeting-kit сохранён в vendor/telemost-meeting-kit: 41 файл с контрольными суммами. В runtime перенесены 16 шаблонов, промпты извлечения/объединения/проверки/рендера и JSON-схемы. YAML преобразован в JSON при разработке; исходные файлы сохранены для сравнения. Новые зависимости и веса на хост не устанавливались.

Вместо запуска standalone pipeline набора реализована очередь в PostgreSQL и Docker-контейнер analysis-worker. Он читает сохранённые транскрипты, извлекает факты по фрагментам, объединяет и проверяет цитаты, затем формирует выбранные отчёты. Кэш фактов позволяет добавить новый отчёт без повторного STT и разбора всех фрагментов. При ошибке кэш сохраняется; повтор выбранных типов доступен в интерфейсе.

## Интерфейс

При загрузке можно выбрать типы разборов и при необходимости указать дату встречи и участников. По умолчанию: короткий итог, конспект, поручения, основные смыслы, оглавление. В карточке встречи доступны дополнительные типы, этап и прогресс обработки, вкладки отчётов, скачивание Markdown и переход по таймкоду в исходный транскрипт.

## Границы

Модель прежняя: локальная qwen3.5:9b в существующей Ollama на хосте. STT — прежний Whisper large-v3 на GPU. GigaAM/pyannote из исходного набора не включены; определения говорящих по голосу сейчас нет. Автоматическая классификация, чат по встрече и сводный дайджест нескольких встреч пока не реализованы; соответствующие исходные материалы сохранены. Отчёты являются черновиками; подтверждение цитат не гарантирует правильную интерпретацию модели. Письмо по итогам только формируется локально. Разборы не отправляют сообщения и не изменяют утверждённый реестр поручений.

[ADR 0003](adr/0003-meeting-kit-analysis-and-templates.md) описывает решения и адаптацию исходных инструкций.
