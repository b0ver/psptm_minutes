1. Восстановить доступ для сверки сервера и получить результаты уже запущенного capacity-run; не запускать новый прогон вслепую.
2. Сохранить/разделить текущие изменения, свести main с merged PR, повторить тесты именно релизного commit.
3. Исправить/квалифицировать dependency advisories и ошибки AI, зафиксировать production-модель/digest. Лабораторные адаптеры не приняты; сравнение Qwen не установило устойчивого победителя.
4. Пройти полный Telegram-путь двумя пользователями, реальную выгрузку Markdown и live-запись после PR #1. Проверить удаление ассистента при остающемся организаторе и непрерывность часового звонка с несколькими участниками.
5. Две реальные встречи из календаря без ручного старта, плюс перенос/отмена на реальном CalDAV; сейчас документирована синхронизация и synthetic-тесты, а не этот полный цикл.
6. Restore, staging deploy и rollback; затем публикация CI/CD, настройка environments/runners/approval и проверка одной и той же версии во всех средах.

Далее: Alembic/baseline и expand-contract миграции; heartbeat и alerts обработчиков; длительности фаз/возраст очередей; bounded retries анализа и dead-letter; admission/квоты/диск; TTL и удаление; egress/GPU arbitration; SBOM/сканирование Chromium/apt/CUDA; общий web с SSO/ACL при необходимости; подтверждённая диаризация как отдельная задача.
