# Зависимости Python основного кандидата, 19 ноября 2026

Полный Docker/PostgreSQL прогон после обновления зависимостей прошел: 428 PASS, 0 FAIL, 2 предупреждения, 18,95 секунды. Production не обновлен. Проверка выполнена на linux/arm64. Проверка финальных образов linux/amd64 остается отдельным условием выпуска.

## Изменения

Runtime lock содержит 49 пакетов. Recorder lock содержит 21 пакет. Оба файла фиксируют версии и SHA256 официальных wheel-пакетов PyPI. Сборка требует проверку хешей через pip --require-hashes. Версии пакетов STT и модельная политика не изменены. Автовыход не изменен.

Прежние lock-файлы содержали 41 известную уязвимость в семи пакетах runtime и одну в recorder. Новый аудит pip-audit не нашел известных уязвимостей Python в обоих lock-файлах. Это результат базы аудита на момент проверки. Он не является оценкой пакетов ОС или браузера.

FastAPI 0.156.8 со Starlette 1.9.0 дали восемь ошибок в тестах загрузки и импорта. Для кандидата выбраны FastAPI 0.133.0 и Starlette 1.3.1. Этот комплект прошел все 428 тестов и аудит Python. Тесты не отключались и не ослаблялись. Проверка pip check прошла. Все 49 установленных версий runtime совпали с финальным lock-файлом.

## Проверки

Команда полного прогона:

```sh
COMPOSE_PROJECT_NAME=psptm-release-compatible-20261119 docker compose -f compose.test.yaml up --build --abort-on-container-exit --exit-code-from tests
COMPOSE_PROJECT_NAME=psptm-release-compatible-20261119 docker compose -f compose.test.yaml down
```

PostgreSQL работал в отдельной internal-сети и tmpfs. Рабочая БД не подключалась. После проверки контейнеры и сеть удалены. Команда down -v не применялась. Настоящие модели, GPU, встречи и доставка Telegram не использовались.

[Машинное подтверждение](python-security-2026-11-19.json) содержит финальные версии, хеши wheel-пакетов, адреса и хеши метаданных PyPI, хеши lock-файлов и результаты проверок. Оно не содержит пользовательских данных.
