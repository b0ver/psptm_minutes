# Minutes RC — предварительные release notes

Дата: 5 ноября 2026. Версия обработки: `minutes-rc-v46-20261105-exact-source`.
Статус: **кандидат подготовлен, к выкатыванию не допущен**.

## Изменения

Промпт больше не требует вычислять календарную дату из относительного срока: исходная формулировка сохраняется, `due_date` остается `null` до подтверждения человеком. Удалено противоречивое требование подставлять имена из списка участников. Список участников, роль в интерфейсе и предполагаемый голос не доказывают исполнителя или авторство реплики.

Разделены значения ссылок: `L00001` — строка источника, номер пункта списка — только номер пункта. Отмененные, исторические и предложенные действия должны оставаться контекстом, без автоматической активации. Это инструкция модели, а не доказанная полнота извлечения.

Проверка цитаты теперь требует ровно одного точного вхождения с сохранением регистра, пробелов и пунктуации. Повторяющаяся цитата не привязывается к первой попавшейся строке. Поддерживается точный фрагмент через границу двух соседних строк с сохранением исходного времени. При неоднозначности прежняя проверка не может принять неподтвержденный пункт.

Исполнитель, автор поручения, исходный срок и подпись цитаты должны встречаться целой дословной фразой: например, «Анна» не подтверждается словом «Жанна». Эти проверки подтверждают только наличие текста, а не смысловую роль человека; дальнейшая проверка результата человеком остается обязательной.

Версия обработки изменена, поэтому прежний кэш фактов не становится результатом новой обработки: сохранен существующий механизм `source_hash` и сброса кэша при изменении версии/ресурсов.

## Что сохранено

Основная версия приложения и конфигурации не изменялась. Ее локальный снимок находится в `baseline/`; список и хеши — в `baseline-manifest.json`. Незакоммиченная работа других задач сохранена.

Модель, allowlist/digest, настройки транспорта, лимиты запросов, отмена, очереди, проверка схемы, даты `null`, проверка человеком, authentication и production-конфигурация не ослаблены. Схема БД не изменена. Frozen v39–v46 не редактировались. Кандидат не отправляет письма и поручения.

## Проверки

439 тестов прошли в Docker с отдельной временной PostgreSQL, включая 14 новых регрессионных проверок. Новые проверки покрывают измененную пунктуацию/регистр/пробелы в цитате, повторяющиеся источники, границу строк, совпадение имени с частью другого имени, исходный срок, противоречия промпта и невозможность принять отсутствующую цитату по одному одобрению модели.

Первый сбор тестов остановился из-за отсутствующего пути импорта лабораторного модуля. В тестовый Compose кандидата добавлен `PYTHONPATH`; после этого полный набор прошел без исключения проверок. Тестовые контейнеры и сеть удалены. Модели/GPU и production БД не использовались.

Отдельный лабораторный v46: 128 новых native controls с аудитом, 689 frozen CPU tests, проверенная отмена четырех конфигураций; последний проверенный результат бенчмарка — **8/24 synthetic, 0/56 real**, новых отказов в этих восьми нет. Это не полная приемка и не доказательство качества прикладного кандидата. Прежний проблемный случай v45 еще не пройден новым профилем.

## Ограничения и условия выпуска

Точная привязка цитат намеренно отклоняет измененные или неоднозначные цитаты. Поэтому может вырасти число пунктов, требующих проверки; эффект на полноту отчетов еще не измерен.

Полный source-only inventory, независимые reviewers и matching pipeline v46 не перенесены в приложение без отдельной интеграции и проверки. Улучшение модельного качества не объявляется доказанным CPU-тестами или заменой промпта.

Перед выкатыванием обязательны:

1. Полный результат v46 24+56 с исходной сверкой источников, всего тела/заголовков/цитат/покрытия и native происхождения.
2. Проверка прикладного кандидата на его собственном разрешенном model/runtime профиле; отмена должна соответствовать этому профилю, лабораторный receipt автоматически не переносится.
3. Staging/E2E полного прикладного цикла и регрессия сохранения результатов/кэша/длинных встреч.
4. Проверенный единый commit и immutable release manifest образов, baseline и процедура rollback по `docs/ci-cd.md`.
5. Обновленные release notes с итогами и остаточными ограничениями, затем отдельное поручение владельца на deploy.

## Выкатывание и откат

Production не менялся. Сейчас откат не требуется. При будущем разрешенном релизе откат выполняется ко всем прежним согласованным image digest одного release manifest; без удаления данных, schema downgrade и переноса экспериментальных кэшей. Локальный baseline не заменяет проверенный backup/restore production.
