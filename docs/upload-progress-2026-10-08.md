# Прогресс загрузки записи

8 октября 2026. В форме добавлен progress с процентом, объёмом переданных байт и aria-live статусом. Отправка FormData использует XMLHttpRequest upload progress. Если браузер не сообщает общий размер, индикатор неопределённый. После передачи тела показывается «Файл передан. Сервер сохраняет запись…», после успешного ответа API — «Запись загружена и передана на обработку».

Пока запрос выполняется, кнопка отправки, выбор файла и название заблокированы, повторная отправка игнорируется. После ошибки поля разблокируются и выбранный файл остаётся для повтора. При потере связи предлагается проверить список встреч, поскольку сервер мог сохранить файл до потери ответа. Ошибка обновления списка после успешной загрузки не выдаётся за ошибку загрузки. Никаких фиктивных процентов AI-обработки нет: дальнейший этап отражает статус встречи.

Обновлён только API-контейнер, worker не перезапускался. API и схема БД не менялись. Browser smoke проверил 50%, счётчик байт, блокировку дубля, различие 100% передачи и ожидания сохранения, потерю связи и повтор, завершение и вкладки. Для успешной тестовой отправки использован управляемый синтетический XHR. Дополнительно настоящий браузерный XHR отправил пустой синтетический файл в серверный API и получил ожидаемый отказ 422; AI-задание не создавалось. Снимки используют только синтетические данные. JavaScript прошёл node --check.
