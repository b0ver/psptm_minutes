# Whisper large-v3 на GPU: 8 октября 2026

По указанию владельца включён GPU-режим нового проекта psptm-minutes на 192.168.1.90. Whisper large-v3 использует RTX 4090, cuda/float16; Ollama остаётся существующей службой хоста.

## Конфигурация

- Worker: отдельный образ psptm-minutes:gpu и overlay compose.gpu.yaml, выделен GPU 0 через NVIDIA DeviceRequests.
- Внутри образа закреплены nvidia-cublas-cu12 12.4.5.8 и nvidia-cudnn-cu12 9.1.0.70. На хост пакеты и драйвер не устанавливались.
- Faster-whisper 1.1.1, CTranslate2 4.8.2. Добавлена явная requests-зависимость: прежние mock-тесты не обнаруживали ошибку импорта STT.
- Монтируется только для чтения /home/epopov/ai-gateway/whisper-cache/hub/models--Systran--faster-whisper-large-v3 в /models/whisper. Директория включает snapshots и blobs, поэтому относительные symlink остаются рабочими.
- STT_MODEL_PATH=/models/whisper/snapshots/edaa852ec7e145841d8ffdb056a99866b5f0a478. Размер имеющегося model.bin — 3 087 284 237 байт; веса не скачивались и не копировались.
- STT_DEVICE=cuda, STT_COMPUTE_TYPE=float16; нет автоматического выбора CPU. Отсутствие GPU или несовместимая точность завершают обработку с безопасным кодом ошибки.
- После STT модель выгружается перед этапом Ollama. Одна задача проекта обрабатывается за раз; это не блокирует AI-задачи других приложений на общей GPU.

## Проверка

GPU-образ собран на сервере. В одноразовом контейнере команда app.check_stt загрузила настоящий large-v3 и выполнила encoder/decoder с выключенным VAD на одной секунде синтетической тишины. Результат:

```json
{"status":"ok","device":"cuda","compute_type":"float16","elapsed_seconds":2.61,"input":"one_second_synthetic_silence","segment_count":1,"real_recording_processed":false,"models_downloaded":false}
```

Это проверка CUDA-библиотек и настоящих модельных вычислений, не оценка качества речи или производительности на встрече. Полученный текст синтетической пробы не сохранялся и не отправлялся в Ollama/Telegram. После выхода одноразового контейнера GPU-память вернулась к прежнему уровню около 671 MiB.

34 теста прошли на сервере за 0.53 s. Новые проверки: отсутствие CPU fallback, отказ неподдерживаемой точности и обязательная выгрузка STT-модели при ошибке. Тестовый Compose-проект удалён после проверки.

Постоянный GPU worker запущен после успешной пробы. API и PostgreSQL продолжают работать; Telegram выключен. В момент начала этапа очередь встреч была пустой — настоящий полный цикл STT → Ollama → протокол пока требует записи.

## Использование

Загрузить тестовую запись в [серверный интерфейс](http://127.0.0.1:18191). Worker обработает её локально, затем создаст протокол и черновики поручений через разрешённую локальную модель Ollama qwen3.5:9b. Секреты, аудио и транскрипт в Telegram не передаются. Реестр требует проверки человеком перед утверждением.

Команды обслуживания только этого worker:

```sh
cd /home/epopov/projects/psptm_minutes
docker compose -f compose.yaml -f compose.gpu.yaml --profile ai up -d --no-build --no-deps worker
docker compose -f compose.yaml -f compose.gpu.yaml --profile ai ps
```

Технические основания: [faster-whisper GPU libraries](https://github.com/SYSTRAN/faster-whisper#gpu), [Docker Compose GPU](https://docs.docker.com/compose/how-tos/gpu-support/). Конкретная совместимость подтверждена GPU-пробой этого образа, а не только документацией.
