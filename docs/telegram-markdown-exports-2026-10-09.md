# Markdown и удалённый доступ

09.10.2026. Пользователь разрешил скачивание материалов по разделам из Telegram. Выдача только в личном чате владельца: «Мои встречи» → встреча → «Скачать Markdown». Доступны транскрипт с таймкодами, каждый готовый шаблонный отчёт и общий Markdown всех готовых разделов. Неполная запись имеет предупреждение; общий файл фиксирует только готовые разделы на момент отправки. Файлы передаются UTF-8 через multipart sendDocument, без Markdown parse_mode. В очередь записываются только идентификаторы; перед отправкой повторно проверяется владелец и готовность. Исторические загрузки без владельца автоматически не присваиваются.

Группа PSPTM_AIForce обнаружена по входящей команде, ID -5008751675. TELEGRAM_STATS_CHAT_ID настроен на этот ID; группа имеет только общий счётчик приложения, файловый экспорт в неё запрещён.

Tailscale адрес сервера: 100.111.184.29. Веб-приложение по-прежнему слушает 127.0.0.1:18190 на сервере. На Mac пользователя открыт SSH-туннель 127.0.0.1:18192 → localhost:18190 сервера через Tailscale. Существующая конфигурация Tailscale Serve для другого приложения не менялась. Адрес http://100.111.184.29:18190 напрямую не опубликован. Полный веб-архив доступен владельцу SSH, Telegram выдаёт только материалы с привязанным владельцем.

Проверка: 100 тестов прошли в изолированном PostgreSQL, в том числе UTF-8, multipart, выбор разделов, предупреждение неполной записи, запрет чужого/группового экспорта и повторная проверка владельца после постановки команды.

Развёртывание подтверждено: бот запущен без перезапусков, командное меню /stats зарегистрировано для PSPTM_AIForce, один реальный запрос статистики имеет sent. getChat подтвердил имя группы; бот в ней уже является администратором. Web /healthz через SSH-туннель возвращает ok. Реальное скачивание пользовательского Markdown после обновления пока отдельно не подтверждено.
