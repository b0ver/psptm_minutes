## Изоляция и воспроизводимость

Compose-проект `psptm-minutes-capacity-20261014-01`: отдельная PostgreSQL на tmpfs, отдельный data volume, отдельный GPU-образ. Production credentials/DB/volumes в стенд не подключены. Выбранные записи скопированы на сервере в защищённый corpus; содержимое не передаётся на компьютер разработки, в Git или журналы CI. Имена примеров в стенде синтетические. Общие GPU и Ollama используются без перенастройки и остановки чужих задач.
