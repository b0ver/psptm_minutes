проверяются перед real-треком. Приватное хранилище имеет права 700, владелец epopov.

Запущен контейнер psptm-benchmark-runner-1 из существующего образа. Перед каждым
вызовом он ждёт обе production очереди и свободную GPU; при последней проверке

пока 0/6240; pilot также ещё не выполнен. ETA без пилота не установлена.

Протокол и основной runner сохраняют фактические неудачи. context_budget_guard
является консервативным отказом до Ollama и не доказывает техническую невозможность
модели. Такие случаи требуют диагностики перед финальным заключением. Для
Gemma2 и CodeLlama зафиксирован compact профиль; качество этого профиля нельзя
смешивать с точной совместимостью production 32768/12000/6000.

Автоматическая оценка synthetic выполняет ограниченные проверки gold assertions,
цитат, задач и разделов. Она не является полной semantic precision/recall. Два
или три независимых локальных семейства судят по полному источнику через чанки,
с дословным evidence. Distill DeepSeek-R1-14B входит в семейство Qwen при
исключении self-judging. Отсутствие подтверждения и противоречие различаются;
споры через чанки требуют человека. Разбиение источника может терять контекст
отмены или указательные связи — это ограничение судей, а не доказательство лжи.

Сценарии русские и жанровые; lecture не содержит искусственных поручений.
160/160 входов уникальны. Шесть unit tests проходят локально и на сервере;
дополнительная диагностика gold facts прошла schema/evidence проверки 160/160.

исчерпывающую экспертную разметку всех категорий.
