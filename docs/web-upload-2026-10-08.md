Отправка доступна после проверки ключа. Выбранный файл сохраняется при входе и ошибке ключа; выход снова блокирует отправку. Серверная аутентификация до разбора multipart остаётся прежней.

Файл теста синтетический и не отправлялся на сервер, задания не создавались. Полный цикл загрузки и AI данным smoke не проверяется. JavaScript прошёл node --check.

## Исправление входа и загрузки одним действием

После обратной связи пользователя отдельная карточка входа убрана. Поле ключа расположено прямо в форме над кнопкой загрузки. Кнопка активна до входа и блокируется только на время запроса. При отсутствии ключа показывается объяснение и фокус переводится в поле; при наличии ключа кнопка сначала проверяет доступ через GET meetings, затем отправляет multipart с записью. Ключ не включается в FormData. Отдельная кнопка «Войти без загрузки» позволяет открыть существующие протоколы.

Повторный Chrome smoke подтвердил отсутствие/неверный ключ без отправки записи, сохранение файла после отказа, успешный общий сценарий входа и загрузки, передачу ключа в Authorization без его включения в тело multipart, переход к встречам и выход. В этом тесте POST загрузки и GET результата перехватывались внутри тестового браузера, настоящими были запросы проверки ключа и чтения списков; задания на сервере не создавались. Кнопка отправки не предполагает обхода серверной аутентификации.

## Снятие ограничения размера файла

По указанию владельца удалён прежний предел 512 MiB: проверка в браузере, ASGI-счётчик тела, проверка Content-Length и проверка размера при сохранении. Загрузка без Content-Length тоже разрешена. Аутентификация до разбора тела, проверка формата, отказ пустому файлу и удаление неполного файла при ошибке сохраняются.

Для API задан TMPDIR=/data/upload-tmp; каталог создаётся при старте в томе recordings. Multipart-временные файлы теперь размещаются на диске, а не в /tmp tmpfs с пределом 600m. Фиксированного предела размера файла нет, доступное место на диске остаётся физическим ограничением. Ограничение длительности декодирования в 2 часа этой правкой не менялось.

34 теста прошли на сервере за 1.67 s, включая реальную загрузку синтетического файла 512 MiB + 1 байт с проверкой сохранённого размера и потоковую multipart-загрузку без Content-Length. Они выполнялись в отдельном тестовом Compose-проекте, реальные AI-задачи не создавались. Для применения заменён только API; GPU worker остаётся запущенным.

Пересобран и заменён только API, GPU-worker не перезапускался. Прежние разделы этого документа описывают промежуточные версии интерфейса.

Для снимка и отправки использованы только синтетические браузерные данные; настоящая AI-очередь не изменялась.
