Автовыход не изменен. Шесть файлов lifecycle и recording controls совпали с прежним production байт в байт. Модельная политика также сохранена. Shared Ollama, GPU и веса моделей не перенастраивались.

## Выкладка

Прием закрывался у Telegram и календаря. Настоящие EXCLUSIVE queue locks удерживались при остановке consumers. Проверены все durable states и отсутствие обработки. Агент остановлен только в idle. После финального согласованного снимка запущены API и рекордер, затем workers, затем producers. БД не пересоздавалась. Production build, down -v и prune не применялись.

После запуска проверены все шесть image refs и revision, HTTP health и proxy, неизвестные stop/status с 404, реальные PostgreSQL session locks worker/analysis/Telegram, новый calendar tick после старта, Telegram getMe и разрешенный digest Ollama. Все 88 сохраненных сессий сохранили прежний общий хеш.

Telegram ограничен двумя подтвержденными операторами. Web остается доступен через loopback/SSH. Recovery control использует отдельный защищенный ключ. Cutoff уведомлений привязан к фактическому freeze; старые календарные пропуски не рассылались повторно. Идентификаторы операторов и секреты остаются вне Git.

Авторитетный private Compose расположен на Bender в main-release-20261119/current/compose.yaml. Previous указывает на сохраненный комплект отката. Одноразовые freeze controllers привязаны к исходным container IDs; перед новым выпуском нужен новый baseline. Автоматический CD остается выключен.
