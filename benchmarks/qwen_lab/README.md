# Qwen lab для отчётов встреч

Эксперименты запускаются отдельно от production и прежнего benchmark. Тексты, сырые ответы, извлечения и разметка находятся только в приватном run-каталоге Bender. В Git публикуются код, план проверок и обезличенные технические результаты.

Первый прогон: `run01`, ранее использованная реальная встреча R01, 3 профиля и 16 шаблонов. MAP6144 и MAP8192 сравниваются при неизменном REDUCE3072; MAP6144/REDUCE6144 сравнивается с MAP6144/REDUCE3072. Остальные параметры остаются исходными: think=false, temperature=0, seed=42, контекст 32768, VERIFY512, RENDER2048. Выбор следующего эксперимента зависит от стадии отказа, полноты извлечений и исходниковой оценки. Ни один шаблон не считается качественным только потому, что JSON и заголовки корректны.

Подготовка на сервере из корня проекта:

```sh
python3 benchmarks/qwen_lab/prepare.py --project .
python3 benchmarks/qwen_lab/run01/lab.py --run benchmarks/qwen_lab/run01
```

Run заморожен manifest, повторная подготовка запрещена. Один runner защищён файловой блокировкой. Лимит запуска 90 минут, уже отправленный запрос ограничен timeout 300 секунд; ожидание gate входит в бюджет. Gate используется от `benchmarks/staged-v2/control.py gate`; свежесть менее 15 секунд, рабочие очереди свободны, GPU utilization менее 15%, чужая Ollama-модель не загружена. Кооперативная проверка не прерывает уже начатый инференс и не является эксклюзивной блокировкой GPU для сторонних приложений.

Для возобновления запустить тот же frozen runner. Успешные вызовы кэшируются по digest модели, артефактам и параметрам запроса. Сохранённые отчёты переиспользуются. Неудачное извлечение сохранено отдельным событием и затрагивает все зависимые шаблоны. Возобновление может повторить неудачное извлечение; такой повтор должен быть отдельным явно отмеченным диагностическим запуском, а не скрытой попыткой получить удачный ответ. Новый эксперимент — новый каталог и manifest.

После генерации остаётся `generation_finished_review_required`: на этом этапе качество и победитель не определены. Подготовленные материалы в `private/review` требуют локальной проверки. Сначала заполняется независимый список ожидаемых атомарных фактов по полному источнику, затем проверяются утверждения каждого отчёта. В спорных местах учитываются соседние реплики, отмены и последующие исправления.

Оценщик принимает JSON-массив разметки. Каждая запись содержит case_id, template, profile, gold_status и review_status (для итогового выбора оба adjudicated), expected с уникальными id, claims с verdict/category/matched_expected_ids/source_spans. source_spans — массив `{segment_id: "L00001", quote: "дословный текст"}`. Для supported требуется точное совпадение цитаты с исходным сегментом. Само совпадение не доказывает смысловую поддержку — это устанавливается разметкой.

```sh
python3 benchmarks/qwen_lab/score_reviews.py /private/reviews.json \
  --inputs /private/inputs.json --output /private/scores.json
python3 -m unittest discover -s benchmarks/qwen_lab -p 'test*.py' -v
```

Скорер не объявляет победителя автоматически. Precision/recall без знаменателя остаются null, неточный source span отклоняется, неопределённые утверждения и непроверенный эталон исключают приёмку. Нулевая критическая ошибка — необходимое, но недостаточное условие. Полный протокол: [Qwen и сравнение с frontier](../../docs/benchmarks/qwen-quality-program-2026-10-11.md).


Диагностика контекста после run01:

```sh
python3 benchmarks/qwen_lab/prepare.py --project . --run-name run02   --context 65536 --profile map6144_reduce6144
python3 benchmarks/qwen_lab/run02/lab.py --run benchmarks/qwen_lab/run02
```

Run01: MAP6144 завершился, REDUCE3072 обрезан. Увеличенные бюджеты на 32768 остановлены conservative context guard; run02 проверяет тот же профиль MAP/REDUCE6144 на 65536. В каталогах run01/run02 записываются только фактические измерения; строки этой инструкции не являются текущей сводкой.

`build_cases.py` создаёт 160 синтетических quality-cases.jsonl. `blind_pairs.py` готовит приватные пакеты A/B и обратный порядок для аудита позиционного смещения. Это инструменты оценки, а не уже выполненное сравнение с frontier.


Локальная вспомогательная проверка (Gemma4:31b) основных четырёх шаблонов:

```sh
python3 benchmarks/qwen_lab/peer_review.py --project . --run benchmarks/qwen_lab/run02
```

Процесс ждёт завершения генерации, использует общую lab.lock и production gate, ограничен 90 минутами вместе с ожиданием. Его оценки — предложения для дальнейшей проверки, не human gold и не frontier-сравнение. Дословные цитаты и ID проверяются автоматически; смысловую корректность и пропуски всё равно нужно подтверждать по источнику.
