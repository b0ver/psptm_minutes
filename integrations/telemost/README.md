# Тестовый ассистент Телемоста

Кандидат от 6 ноября: [бэклог, устройство и приемка](../../docs/sprints/2026-11-06-continuous-recording.md). Агент остается до завершения встречи, исключения или явной команды. Время календаря и ожидаемая длительность не запускают выход. Штатные файлы меняются через 29 минут; аудиокопия использует один выходной поток. Production еще не обновлен. Настоящий длинный звонок и селекторы чата требуют приемки.

Дополнительные проверки без сети: `python lifecycle_probe.py` и `python rollover_probe.py` внутри одноразового контейнера агента. Первая проверяет команды и экраны на синтетическом DOM. Вторая запускает настоящий основной цикл агента на синтетической странице, проверяет восемнадцать сценариев, сохранение файлов, единичный импорт и непрерывность тестового звука.

Docker Chromium + Playwright: видимый гостевой вход, выключенные камера/микрофон, штатная запись на компьютер и передача в приложение. Шаги UI сверены с тестовой встречей 8 октября 2026; дальнейшие изменения интерфейса могут потребовать адаптации.

```sh
docker compose -f compose.yaml -f compose.telemost.yaml --profile telemost build telemost-agent
docker compose -f compose.yaml -f compose.telemost.yaml --profile telemost up -d --no-deps telemost-agent
```

После обновления API/интерфейса управление доступно в основном приложении, раздел «Подключить ассистента к Телемосту». Endpoint агента не публикуется. При отключённом профиле интерфейс показывает его недоступность.

Серверное хранилище: volume recordings, каталог telemost/<UUID>, состояние state.json, диагностический preview.png, завершённая recording.webm. Ссылку встречи не включать в Git/логи. Состояния сессии не равны статусу транскрибации: uploaded означает, что файл передан приложению, а не что отчёты уже готовы. Никаких отправок сообщений или переключения модели.

Агент одновременно обслуживает одну встречу. Аудиокопия штатного рекордера сохраняет последовательные части на диск; после сбоя доступна обработка восстановленного префикса с пометкой неполной записи. Повтор импорта проверяет квитанцию и не создаёт вторую встречу. Число частей и задержка сохранения видны в интерфейсе. Новый механизм проверен на синтетическом аудио и на живой трёхминутной встрече: сохранено 19 частей, аудио совпало по длительности и измеренным уровням со штатным файлом. Длинный тест с несколькими участниками ещё нужен. Подробности: [ADR 0005](../../docs/adr/0005-telemost-durable-recording-and-idempotent-import.md).

На сервере проверены допуск организатора, вход, трёхминутная запись, скачивание WebM, импорт, транскрибация и базовый протокол. Дополнительные разборы обрабатываются общей очередью. Для TLS серверов связи нужен закреплённый [корневой сертификат](certs/README.md); он устанавливается только внутри контейнера. [Отчёт о проверке](../../docs/deployment-telemost-2026-10-08.md).

Офлайн-проверка в отдельном контейнере без сети и пользовательских записей:

```sh
docker run --rm --network none --read-only --tmpfs /tmp:size=256m,mode=1777 --shm-size=512m --cap-drop=ALL --security-opt=no-new-privileges psptm-minutes:telemost python probe.py
```

Проверка запуска и остановки записи в обоих вариантах интерфейса (отдельная кнопка с `aria-label` и прежний пункт меню), задержки появления кнопки и отказа при отсутствии подтверждения:

```sh
docker run --rm --network none --read-only --tmpfs /tmp:size=256m,mode=1777 --shm-size=512m --cap-drop=ALL --security-opt=no-new-privileges psptm-minutes:telemost python recording_controls_probe.py
```

Проба использует синтетическую страницу внутри iframe; к встречам не подключается. Она проверяет выбор команды остановки, но не скачивание настоящего аудиофайла Телемоста.

`python checkpoint_scope_probe.py` проверяет в Chromium, что остановка вспомогательного MediaRecorder не завершает аудиокопию основного рекордера. Проверка включена в CI и выпуск кандидата.

Общий обработчик не нажимает «Закрыть окно». До начала записи он закрывает только явно названное ознакомление. При записи он не закрывает окна.

При своей смене файла агент удерживает только входы выбранного штатного микшера до старта следующего рекордера. Он освобождает их после перехода, отмены или отказа. Аудиодиагностика не заменяет штатный видеорекордер. Незапрошенный стоп не вызывает повторный старт. Проверка настоящего длинного звонка остается отдельным условием приемки.

### Данные браузера

Каждая сессия получает отдельный дисковый профиль в своем каталоге /data. Каталоги browser-profile, browser-downloads, browser-config и browser-cache закрыты для других пользователей. Они могут содержать приватные данные встречи. Не включайте их в Git, CI logs или публичные artifacts. После полного успешного импорта и закрытия браузера агент удаляет эти каталоги. При ошибке или неполной записи они остаются для восстановления. Запись и checkpoints сохраняются отдельно. Проверка без сети: `python browser_session_probe.py` внутри образа агента.

При недоступности дополнительных штатных файлов агент сохраняет проверенную финальную аудиокопию. В статусе появляются native_export_warning и счетчики native_files_expected/native_files_saved. Ошибка выгрузки дополнительных файлов не доказывает неполноту аудио. Ошибка самого захвата или разрыв по-прежнему помечает аудиозапись неполной. При предупреждении профиль остается для восстановления. Причина выхода end_reason и ошибка сохранения error_code учитываются отдельно.

Повторный запуск ждет доступную команду до 60 секунд, общий переход ограничен 90 секундами. После подтвержденного старта повторы прекращаются. Отмена и конец встречи проверяются во время ожидания. Отключенная команда прекращает переход. rotation_error_code содержит только известный код этапа; rotation_elapsed_seconds содержит длительность перехода. Текст исключения в статус не попадает.
