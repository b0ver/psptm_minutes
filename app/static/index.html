Яндекс Календарь · автоматическое подключение к встречам

Подключите календарь один раз. Ассистент будет сам находить ссылки Телемоста и входить по расписанию. Включение автоматической записи доступно после просмотра ближайших встреч.

Создайте отдельный пароль в Яндекс ID → Безопасность → Пароли приложений → Календарь. Новый пароль может заработать через 2–3 часа.
